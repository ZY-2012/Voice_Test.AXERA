| voxpopuli | 英语 | 欧洲议会演讲 | 1,842 | 4.9h | 9.6s | ✅ |
| tedlium | 英语 | TED 演讲 | 1,142 | 2.6h | 8.2s | ✅ |

### 1.2 中文测试集（AISHELL-1）

来源：ModelScope `modelscope/speech_asr_aishell1_testsets`（[链接](https://www.modelscope.cn/datasets/modelscope/speech_asr_aishell1_testsets)）

| 指标 | 数值 |
|---|---|
| 语言 | 中文普通话 |
| 内容类型 | 朗读语音（录音室，干净）|
| test 样本数 | 7,176 条（另有 dev 14,331 条保留在 vad/aishell1/ 原始目录）|
| 总时长 | 约 20.2 小时 |
| 音频格式 | 16kHz 单声道 PCM16 wav（原始即 16k）|
| 转写格式 | 汉字 + 空格分词（官方格式）；`text.nospace` 提供去空格字级版本 |

### 1.3 ASR 数据制作方法

1. **下载**：见 `asr/download_esb_aria2.sh`（ESB 英文，aria2c，hf-mirror 加速）与 ModelScope CLI：
   ```bash
   modelscope download --dataset modelscope/speech_asr_aishell1_testsets --local_dir vad/aishell1
   ```
2. **整理**：`asr/prepare_asr_test.py` — tar/parquet 解压 → 统一 16kHz PCM16 wav + `wav.scp` + `text`
3. **格式**：每个子集目录下 `wav/<utt_id>.wav`、`wav.scp`（utt_id→路径）、`text`（utt_id→转写）
4. **注意**：gigaspeech 按 ESB 官方预处理（小写、标点归一、纯噪声段过滤 25619→19931）；earnings22 已清垃圾标记

### 1.4 ASR 评估方法

- 英文：WER（词错误率），参考文本与识别结果均需归一化（转小写、去标点）
- 中文：CER（字错误率），去标点、转小写；`text.nospace` 直接用于字级比对
板端实测指标见顶层 README「已适配模型指标」自动表（`tools/report.py` 生成）。

## 2. VAD（语音活动检测）

两套英文测试集，语音素材相同（LibriSpeech test-clean，2620 条），标签体系不同：

### 2.1 Picovoice 风格（长流式）

来源：[Picovoice/voice-activity-benchmark](https://github.com/Picovoice/voice-activity-benchmark)

| 指标 | 数值 |
|---|---|
| 评测音频 | `vad/picovoice/test_audio.wav`：19.92 小时单条长流（2620 句 + 句间 20s 静音 + DEMAND 噪声 0dB 混合）|
| 标签 | `benchmark_labels.txt`：2,241,489 帧，每帧 512 采样点（32ms），三值 0=静音/1=未知/2=语音 |
| 标签分布 | 静音 171.7 万 / 未知 22.6 万 / 语音 29.8 万帧（语音占 13.3%）|
| 噪声 | DEMAND 18 环境（排除 8 个含人声环境，实际用 160 个噪声文件），随机种子 778（可复现）|

### 2.2 LibriVAD 风格（逐句采样级）

来源：[LibriVAD/LibriVAD](https://huggingface.co/datasets/LibriVAD/LibriVAD)（arXiv 2512.17281）

| 指标 | 数值 |
|---|---|
| 样本 | `vad/librivad/test/`：2620 条 wav + 采样级标签 |
| 标签 | `labels/<utt_id>.npy`：与音频同采样率（16kHz）逐点二值 0=静音/1=语音 |
| 标签来源 | 官方强制对齐 TextGrid（词级时间戳，`Files/Forced_alignments.zip`）→ 官方 `create_labels.py` 逻辑导出 |
| 质量示例 | 语音占比典型 60~90%（如 1089-134686-0000：10.44s 中 89.5% 语音）|

### 2.3 中文 VAD ✅

- 数据：`vad/aishell1/test/` — 7176 条 + 采样级 0/1 标签（`labels/*.npy`）+ `test.scp`
- 标签：funasr fsmn-vad 模型生成（模型标签，非人工对齐；制作脚本 `vad/gen_aishell_vad_labels.py`）

### 2.4 VAD 数据制作方法

1. 下载：LibriSpeech 音频（复用 asr 的 test-clean wav）、DEMAND 噪声（Kaggle `aanhari/demand-dataset`）、`Files/Forced_alignments.zip` + `Files/Noises.zip`（LibriVAD HF 仓库）
2. 生成：
   - Picovoice：`gen_picovoice_test.py`（官方 mixer.py 逻辑原样：拼接+0dB 混噪+能量打标）
   - LibriVAD：`gen_librivad_test.py`（官方 create_labels.py 逻辑原样：TextGrid→采样级标签）
3. 输出均为「音频 + 帧/采样级标签」对，可直接喂 VAD 模型

### 2.5 VAD 评估方法

- 帧级准确率：TP（语音帧命中）/FP（静音帧误报）→ 绘制 ROC（Picovoice 官方方法）
- 帧级 F1 / 事件级指标（语音段起止时间误差）
- Axera 已适配模型：**SileroVAD**（AX650N/AX630C）
  - RTF：0.029（整段）/ 0.0297（32ms 流式，0.95ms/chunk），加载 1.48s
  - 内存：CMM 0.7MB / OS 241.8MB
  - 支持灵敏度、静音时长可调；输出 start_ts/end_ts/audio

## 3. SE（语音增强）✅

### 3.1 建议数据集：VoiceBank-DEMAND

- 标准 SE 评测集：824 对（clean + noisy），16kHz，来自 Noisy Speech Database for Training Speech Enhancement Algorithms
- 下载地址：HuggingFace 镜像 `JacobLinCool/VoiceBank-DEMAND-16k`（test 分片）
- 性质指标：824 条 ×2（干净/带噪），平均 ~4s，噪声类型 40 种（10 种噪声 × 4 SNR：0/5/10/15dB）

### 3.2 制作方法

1. HF 下载 clean+noisy 测试对 → 解包到 `se/voicebank_demand/`（clean/ 与 noisy/ 两个目录，文件名一一对应）
2. 无需额外处理（本身 16k wav）

### 3.3 评估方法

- 客观指标：PESQ（`torch-pesq` 已装于 base）、STOI（`pystoi`）、SI-SNR + RTF
- 主观：MOS（可选）
- Axera SE 模型：**已接入 GTCRN（16k）、FastEnhancer（16k/48k）**，命令见 `tools/model_registry.py`，板端 `bash se/run.sh` 出指标

## 4. TTS（语音合成）✅

### 4.1 建议数据集

| 数据集 | 语言 | 规模 | 下载地址 | 用途 |
|---|---|---|---|---|
| LJSpeech | 英语 | test 500 条（全量 13,100 条 / 24h）| HF 镜像 `flexthink/ljspeech` | 英文 TTS 评测 |
| AISHELL-3 | 中文 | test 1,948 条 / 100 说话人（HF 子集；官方 test 24,773 条）| HF `AISHELL/AISHELL-3` | 中文 TTS 评测 |

### 4.2 制作方法

1. 下载上述测试子集（各取 test split：LJSpeech 常用后 1300 条做 test；AISHELL-3 官方 test 约 5%）
2. 提取「测试文本清单 + 参考音频（可选，用于说话人相似度）」，音频统一 16k（TTS 输出多为 24k，评测时需对齐采样率）
3. 无需转写（转写即输入文本）

### 4.3 评估方法

- 合成音频可懂度：用已适配的 ASR 模型（SenseVoice/Whisper）识别合成音频 → 与输入文本算 CER（越低越好）
- 音质：MCD（梅尔倒谱距离）、PESQ（需参考音频时）
- 说话人相似度：说话人向量余弦相似度（如 3D-Speaker 等，可选）
- 实时性：RTF（合成音频时长/耗时）
- Axera TTS 模型：**已接入 Kokoro / MeloTTS（预设音色）、ZipVoice / CosyVoice2（零样本）**，
  主指标回环 CER（合成音过 SenseVoice 识别 vs 输入文本），板端 `bash tts/run.sh` 出指标
